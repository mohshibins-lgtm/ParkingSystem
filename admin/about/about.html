About This Project

This project is a web-based parking management system. It allows users to allocate and remove parking slots efficiently. The system supports multiple roles including staff and admin users for better management.

The admin panel provides secure access for management tasks, while the staff page allows day-to-day operation handling. This page will be updated with more details soon.

Key Features

  • Vehicle slot allocation and removal
  • Staff management with secure login
  • Admin control with password protection
  • Real-time dashboard and history tracking
